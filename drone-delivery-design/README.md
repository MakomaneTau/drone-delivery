# Drone delivery simulation design package

Prepared for Makomane Tau on 23 October 2026.

This package contains two implementation planning documents and repository instructions. It does not contain an implemented simulator or application.

- `docs/CODEX_IMPLEMENTATION.md` gives Codex milestone tasks, boundaries, exit criteria, and a starter prompt.
- `docs/SOFTWARE_DESIGN.md` defines the complete simulation software architecture, mission model, API, persistence, physics, interfaces, tests, and later extensions.
- `AGENTS.md` supplies instructions for Codex in the implementation repository.
- `Drone_Delivery_Software_Design.docx` is the formatted review copy of the full software design.

Extract the package into a new project directory or merge the design files carefully into an existing repository. If that repository already has AGENTS.md, combine the relevant guidance instead of overwriting it. Open the directory in Codex and use the starter prompt at the end of the implementation guide.

The selected first release is a local simulation with one drone in a generic world on a 16 GB Windows laptop. Numeric experiment settings are proposed defaults. Exact flight tool versions, laptop performance, and simulator capabilities must pass M0 before being treated as verified.
